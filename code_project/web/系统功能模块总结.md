## 二、新闻中心模块

### 模块概述
新闻中心提供新闻列表展示、搜索、分类等功能，是信息发布的核心模块。

### 已实现功能

| 序号 | 功能名称 | 功能描述 | 技术实现 |
|------|---------|---------|---------|
| 1 | 新闻搜索 | 实时关键字搜索，输入即显示匹配结果 | Axios + 计算属性 `computed` |
| 2 | 热门新闻 | 展示最新的 4 条热门新闻 | 数组 `slice(0, 4)` 截取 |
| 3 | 新闻分类 | 分为"最新动态"、"典型案例"、"通知公告"三个分类 | Lodash `groupBy` 分组 |
| 4 | 分类标签 | 使用 Tab 切换不同分类新闻 | Element Plus `el-tabs` |
| 5 | 新闻卡片 | 展示新闻封面、标题、发布时间 | Element Plus `el-card` |
| 6 | 时间轴视图 | 侧边栏以时间轴形式展示新闻 | Element Plus `el-timeline` |
| 7 | 返回顶部 | 快速返回页面顶部 | Element Plus `el-backtop` |
| 8 | 中文时间 | 发布时间格式化为中文格式 | Moment.js `moment().format()` |

### 技术要点
- **实时搜索**: 使用 `computed` 计算属性实现搜索结果过滤
- **数据分组**: 使用 Lodash 的 `groupBy` 按新闻分类分组
- **时间处理**: Moment.js 本地化为中文格式 `moment.locale("zh-cn")`
- **图片加载**: 从后端接口获取封面图片 `http://localhost:3000${item.cover}`

### 数据流程
```
onMounted → GET /webapi/news/list → newsList → 计算属性处理 → 渲染展示
```

## 三、新闻详情模块

### 模块概述
新闻详情页展示单条新闻的完整内容，提供相关新闻推荐。

### 已实现功能

| 序号 | 功能名称 | 功能描述 | 技术实现 |
|------|---------|---------|---------|
| 1 | 详情展示 | 显示新闻标题、发布时间、正文内容 | `watchEffect` 监听路由变化 |
| 2 | 富文本渲染 | 支持图片、表格等富文本内容展示 | `v-html` 指令 |
| 3 | 相关推荐 | 侧边栏展示最近 4 条新闻 | GET /webapi/news/toplist |
| 4 | 路由导航 | 点击相关新闻跳转到对应详情页 | Vue Router `router.push()` |
| 5 | 视觉分隔 | 标题与内容之间使用分隔线 | Element Plus `el-divider` |
| 6 | 图标装饰 | 分隔线中心显示星形图标 | Element Plus Icons |

### 技术要点
- **动态路由**: 使用 `/news/:id` 动态路由参数
- **响应式数据**: `watchEffect` 自动监听路由参数变化并重新请求数据
- **富文本支持**: 使用 `v-html` 渲染后端返回的 HTML 内容
- **深度选择器**: 使用 `::v-deep` 修改富文本内容的样式（如图片宽度）

### 数据流程
```
路由变化 /news/:id → watchEffect → 并发请求两个接口 → 渲染详情 + 侧边栏推荐
```

## 四、产品展示模块

### 模块概述
产品展示页以垂直轮播方式展示企业产品，提供产品详情信息。

### 已实现功能

| 序号 | 功能名称 | 功能描述 | 技术实现 |
|------|---------|---------|---------|
| 1 | 产品列表 | 从后端获取所有产品信息 | GET /webapi/product/list |
| 2 | 垂直轮播 | 使用垂直方向轮播展示产品 | Element Plus `direction="vertical"` |
| 3 | 产品封面 | 展示产品封面背景图 | 背景图 + 渐变遮罩 |
| 4 | 产品详情 | 展示标题、简介、详细描述 | Element Plus `el-card` |
| 5 | 悬停效果 | 鼠标悬停卡片上浮 + 阴影增强 | CSS `hover` + `transform` |
| 6 | 淡入动画 | 页面加载时卡片淡入上移 | CSS `@keyframes fadeInUp` |
| 7 | 响应式设计 | 适配 1200px/768px/480px 断点 | 媒体查询 `@media` |
| 8 | 空状态处理 | 无产品时显示空状态提示 | Element Plus `el-empty` |
| 9 | 卡片滚动 | 产品详情过长时支持滚动 | 自定义滚动条样式 |

### 技术要点
- **垂直轮播**: 禁用自动播放 `autoplay="false"`，仅支持手动切换
- **背景处理**: 产品背景图添加渐变遮罩，提升文字可读性
- **毛玻璃效果**: 卡片使用 `backdrop-filter: blur(10px)` 实现毛玻璃效果
- **响应式适配**: 三个断点（1200px、768px、480px）适配不同屏幕

### 响应式断点
| 屏幕宽度 | 卡片宽度 | 字体大小 |
|---------|---------|---------|
| > 1200px | 45% | 1rem |
| 768px - 1200px | 55% | 1rem |
| 480px - 768px | 85% | 0.9rem |
| < 480px | 95% | 0.85rem |

## 五、导航栏模块

### 模块概述
导航栏提供网站全局导航，固定在页面顶部，支持路由跳转和外部链接。

### 已实现功能

| 序号 | 功能名称 | 功能描述 | 技术实现 |
|------|---------|---------|---------|
| 1 | 导航菜单 | 首页、新闻中心、产品与服务三个菜单项 | Element Plus `el-menu` |
| 2 | 路由绑定 | 点击菜单项跳转到对应路由 | Vue Router `:router='true'` |
| 3 | 激活状态 | 当前路由对应的菜单项高亮显示 | `:default-active="route.fullPath"` |
| 4 | 登录入口 | 点击"登录"跳转到后台管理系统 | `window.open("http://localhost:8080")` |
| 5 | 品牌标识 | 右上角固定显示"企业门户官网" | 绝对定位 `position: fixed` |
| 6 | 固定定位 | 导航栏固定在页面顶部，不随滚动消失 | `position: sticky` |
| 7 | 菜单样式 | 水平布局的菜单栏 | `mode="horizontal"` |

### 技术要点
- **路由高亮**: 使用 `useRoute()` 获取当前路由，绑定到 `default-active`
- **外部链接**: 使用 `window.open()` 在新窗口打开后台管理系统
- **固定导航**: `position: sticky` 导航栏始终固定在顶部

## 六、路由与状态管理模块

### 模块概述
负责应用路由配置和页面切换时的状态管理。

### 已实现功能

| 序号 | 功能名称 | 功能描述 | 技术实现 |
|------|---------|---------|---------|
| 1 | 路由配置 | 定义 4 个路由，包括动态路由 | Vue Router `createRouter` |
| 2 | 路由守卫 | 页面切换时显示加载进度条 | NProgress `beforeEach` / `afterEach` |
| 3 | 历史模式 | 使用 HTML5 History 模式 | `createWebHistory()` |
| 4 | 路由嵌套 | 在 App.vue 中嵌套路由视图 | `<RouterView />` |

### 路由配置表

| 路径 | 组件 | 路由类型 | 说明 |
|------|------|---------|------|
| `/` | Home.vue | 静态路由 | 首页 |
| `/news` | News.vue | 静态路由 | 新闻列表 |
| `/news/:id` | New.vue | 动态路由 | 新闻详情 |
| `/product` | Product.vue | 静态路由 | 产品展示 |

### 路由守卫流程
```
路由切换开始 → beforeEach → NProgress.start() → 路由跳转 → afterEach → NProgress.done()
```

# 企业门户官网项目总结

## 项目概述

本项目是一个基于 Vue 3 + Node.js 的企业门户网站系统，采用前后端分离架构，提供企业展示、新闻发布、产品介绍等核心功能。项目包含 Web 前端（本目录）、Admin 管理后台和 Server 服务端三个部分。

## 功能需求分析

### 1. 用户需求分析

#### 1.1 企业展示需求
企业需要通过互联网展示企业形象和文化，提升品牌知名度和市场竞争力。需要一个专业、美观的官网平台来对外宣传企业的产品和服务。

#### 1.2 信息发布需求
企业需要及时发布新闻动态、通知公告、典型案例等信息，让访客了解企业的最新发展和成就。需要一个内容管理系统来方便地发布和管理这些信息。

#### 1.3 产品推广需求
企业需要展示其产品和服务，包括产品图片、介绍、详细说明等信息，让潜在客户快速了解产品特点和优势。

#### 1.4 用户访问需求
访客需要方便快捷地浏览网站内容，快速找到感兴趣的信息，并能够通过搜索功能快速定位到相关内容。

#### 3.1 性能需求
- **页面加载时间**: 首页加载时间不超过 2 秒

- **图片优化**: 图片资源需要进行压缩和优化

#### 3.2 可用性需求
- **用户友好**: 界面简洁美观，操作直观易用
- **兼容性**: 支持主流浏览器（Chrome、Firefox、Safari、Edge）
- **响应式**: 支持桌面端、平板、手机等多种设备

#### 3.3 安全需求
- **跨域处理**: 开发环境通过代理解决跨域问题
- **XSS 防护**: 富文本内容需要进行安全过滤

#### 3.4 可维护性需求
- **代码规范**: 遵循 Vue 3 开发规范
- **组件化**: 功能模块组件化，提高复用性

## 核心功能模块

### 1. 首页（Home.vue）

- **轮播图展示**: 使用 Element Plus 轮播组件展示企业宣传图
- **全屏设计**: 轮播图高度为 `calc(100vh - 60px)`，占据整个可视区域
- **视觉焦点**: 中心位置展示"互联网+时代"主题标语

### 2. 新闻中心（News.vue）

- **新闻搜索**: 实时搜索功能，支持关键字检索
- **热门新闻**: 展示最新的 4 条热门新闻
- **分类标签**: 分为"最新动态"、"典型案例"、"通知公告"三个分类
- **新闻卡片**: 展示新闻封面、标题、发布时间
- **时间轴**: 侧边栏提供新闻时间轴视图
- **返回顶部**: 添加回到顶部按钮，提升用户体验

**主要特性:**
- 使用 Lodash 进行新闻分类
- Moment.js 实现中文时间格式化
- Element Plus Popover 实现搜索结果弹窗
- 响应式布局设计

### 3. 新闻详情（New.vue）

- **详情展示**: 显示新闻标题、发布时间、正文内容
- **富文本渲染**: 使用 `v-html` 渲染新闻富文本内容
- **相关推荐**: 侧边栏展示最近新闻
- **路由导航**: 支持点击相关新闻跳转
- **视觉分隔**: 使用 Element Plus 分隔线组件

### 4. 产品与服务（Product.vue）

- **垂直轮播**: 展示产品图片和信息
- **卡片展示**: 每个产品以卡片形式展示
- **产品信息**: 包含标题、简介、详细描述
- **响应式设计**: 适配不同屏幕尺寸
- **动画效果**: 卡片悬停动画、淡入上移动画
- **空状态处理**: 无产品时显示空状态提示

### 5. 导航栏（Navbar.vue）

- **菜单导航**: 首页、新闻中心、产品与服务
- **路由绑定**: 使用 Vue Router 实现页面跳转
- **登录入口**: 跳转至后台管理系统（http://localhost:8080）
- **品牌标识**: 右上角显示"企业门户官网"
- **固定定位**: 导航栏固定在顶部

## 路由配置

| 路径 | 组件 | 说明 |
|------|------|------|
| `/` | Home | 首页 |
| `/news` | News | 新闻列表 |
| `/news/:id` | New | 新闻详情（动态路由） |
| `/product` | Product | 产品展示 |

## API 接口

项目通过 Axios 与后端 Node.js 服务通信，接口统一使用 `/webapi` 前缀：

- `GET /webapi/news/list` - 获取新闻列表
- `GET /webapi/news/list/:id` - 获取新闻详情
- `GET /webapi/news/toplist?limit=4` - 获取热门新闻
- `GET /webapi/product/list` - 获取产品列表

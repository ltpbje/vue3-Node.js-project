# 并发用户访问测试

## 测试说明

本测试套件用于模拟并发用户访问后台管理系统和门户网站，评估系统在高并发情况下的性能表现。

## 测试场景

### 后台管理系统测试
- **并发用户数**: 50 个用户
- **测试时长**: 60 秒
- **测试接口**:
  - 用户列表: GET /adminapi/user/list
  - 新闻列表: GET /adminapi/news/list
  - 产品列表: GET /adminapi/product/list

### 门户网站测试
- **并发用户数**: 100 个用户
- **测试时长**: 60 秒
- **测试接口**:
  - 新闻列表: GET /webapi/news/list
  - 产品列表: GET /webapi/product/list

## 环境要求

- Node.js >= 14.0.0
- 后端服务器运行在 http://localhost:3000
- 测试用户账号: admin / 123456

## 安装依赖

```bash
cd test-data
npm install
```

## 运行测试

### 运行所有测试
```bash
npm run test:all
```

### 仅测试后台管理系统
```bash
npm run test:admin
```

### 仅测试门户网站
```bash
npm run test:web
```

## 测试指标

- **吞吐量**: 每秒处理的请求数 (req/s)
- **响应时间**: 平均、最小、最大响应时间
- **百分位响应时间**: P50, P90, P95, P99
- **失败率**: 失败请求的百分比

## 预期结果

### 后台管理系统
- 吞吐量 ≥ 100 req/s
- 平均响应时间 ≤ 200ms
- 失败率 ≤ 1%

### 门户网站
- 吞吐量 ≥ 200 req/s
- 平均响应时间 ≤ 150ms
- 失败率 ≤ 0.5%

## 注意事项

1. 确保后端服务器正常运行
2. 确保数据库连接正常
3. 测试期间监控系统资源使用情况
4. 避免在生产环境中运行测试

# API接口响应时间测试报告

## 测试概述

**测试时间**: 2026年3月2日 19:53:29  
**测试工具**: Axios + Node.js  
**目标服务器**: http://localhost:3000  
**每个接口测试次数**: 20 次  
**超时设置**: 5000 ms

## 测试结果

### 门户网站接口 ✅

| 接口 | 平均响应时间 | 最小响应时间 | 最大响应时间 | 成功率 |
|------|-------------|-------------|-------------|--------|
| GET /webapi/news/list | **7 ms** | 3 ms | 46 ms | 100.0% |
| GET /webapi/product/list | **4 ms** | 3 ms | 4 ms | 100.0% |

**结论**: 门户网站接口响应速度极快，平均响应时间在 10ms 以内，成功率 100%。

### 后台管理系统接口 ❌

| 接口 | 平均响应时间 | 最小响应时间 | 最大响应时间 | 成功率 |
|------|-------------|-------------|-------------|--------|
| GET /adminapi/user/list | N/A | N/A | N/A | 0% |
| GET /adminapi/news/list | N/A | N/A | N/A | 0% |
| GET /adminapi/product/list | N/A | N/A | N/A | 0% |

**问题**: 所有后台管理系统接口请求均超时（超过 5000ms），无法正常响应。

## 问题分析

### 门户网站接口
- **性能优异**: 平均响应时间 4-7ms，远超预期
- **稳定性好**: 成功率 100%，无失败请求
- **用户体验**: 响应速度极快，用户体验优秀

### 后台管理系统接口
- **认证正常**: 登录接口响应正常，令牌获取成功
- **请求阻塞**: 所有业务接口请求被挂起，超过 5 秒后超时
- **可能原因**:
  1. **数据库连接池耗尽**: 高并发时数据库连接被占用，无法释放
  2. **中间件阻塞**: 认证中间件或权限检查阻塞请求
  3. **请求队列堆积**: 请求处理队列堆积，导致后续请求无法处理
  4. **资源竞争**: 多个请求竞争同一资源，导致死锁

## 性能对比

### 门户网站 vs 后台管理系统

| 对比项 | 门户网站 | 后台管理系统 |
|--------|---------|-------------|
| 平均响应时间 | 4-7 ms | > 5000 ms |
| 成功率 | 100% | 0% |
| 性能状态 | 优秀 | 异常 |

## 根本原因分析

### 为什么门户网站正常，后台管理系统异常？

1. **认证机制差异**:
   - 门户网站接口无需认证，直接访问
   - 后台管理系统接口需要 JWT 认证，增加了处理环节

2. **数据库查询差异**:
   - 门户网站可能使用简化的查询
   - 后台管理系统可能涉及更复杂的查询和权限检查

3. **中间件差异**:
   - 后台管理系统有额外的认证和权限中间件
   - 这些中间件可能存在阻塞问题

```javascript
    next();

});
```

3. **添加请求超时**:
```javascript

  req.setTimeout(5000, () => {
    res.status(408).send({ error: '请求超时' });
  });
  next();
});
```
